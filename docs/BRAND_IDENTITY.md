# Euryphos — name and pronunciation

## Product name

**Euryphos** is the product's working name and the canonical spelling used by the source tree, binaries, service names, configuration variables, data paths, Docker resources, and documentation.

## Pronunciation

For the English product name, use **YOO-rih-fohs** (three syllables, primary stress on the first syllable). Pronounce `ph` as `f`.

This is a recommended English brand pronunciation, not a claim that the coined product name has a single historically correct Ancient Greek pronunciation.

## Mythological and linguistic inspiration

Euryphos is a modern coined product name. It is inspired by **Euryphaessa** (Εὐρυφάεσσα), an epithet/name associated with the Greek Titaness Theia. A scholarly discussion of Greek etymology analyzes Euryphaessa as meaning “widely shining,” from the Greek element *eury-* (“wide, broad”) and a shining-related form. The product name also deliberately recalls Ancient Greek **φῶς** (*phōs*), meaning “light.”

The branding is intended to evoke broad visibility, illumination, and the ability to bring the state of a managed environment into view. Euryphos is not itself presented as the historical name of a Greek deity.
